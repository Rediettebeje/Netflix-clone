Netflix Clone
A Netflix clone built with React, Axios, and the TMDB API to fetch and display movie data. This project mimics the core features of Netflix, including browsing movies by category, viewing details, and playing trailers.

Features

Movie Browsing: Browse movies by categories such as Trending, Top Rated, Action, Comedy, etc.
Trailer Playback: Click on a movie poster to watch its trailer.
API Integration: Fetches data from the TMDB API.

Technologies Used
React
Axios
YouTube API
TMDB API
CSS
