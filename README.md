Netflix Clone
A Netflix clone built with React, Axios, and the TMDB API to fetch and display movie data. This project mimics the core features of Netflix, including browsing movies by category, viewing details, and playing trailers.

Features

Movie Browsing: Browse movies by categories such as Trending, Top Rated, Action, Comedy, etc.
Trailer Playback: Click on a movie poster to watch its trailer.
API Integration: Fetches data from the TMDB API.

Technologies Used
React
Axios
YouTube API
TMDB API
CSS
Installation
Clone the repository:
git clone https://github.com/yourusername/netflix-clone.git

Navigate to the project directory:
cd netflix-clone

Install dependencies:
npm install

Create a .env file in the root directory and add your TMDB API key:
REACT_APP_TMDB_API_KEY=your_api_key_here

Start the development server:
npm start

Usage
Open your browser and go to http://localhost:3000 to view the app.
Browse through different categories and click on a movie poster to watch its trailer.
